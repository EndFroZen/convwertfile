# CuthrusGlaucus

แอปเดสก์ท็อปสำหรับแก้ไขรูปภาพและแปลงไฟล์ ใช้งานได้บนเครื่องโดยไม่ต้องอัปโหลดไฟล์ขึ้นเว็บ (ยกเว้น PDF เป็นข้อความ)

## ความสามารถ

### Image Editor
- หมุน พลิก ปรับขนาด
- ปรับความสว่าง คอนทราสต์ ความอิ่มสี
- ครอป ยางลบ ลบพื้นหลังตามสี (ระบายส่วนที่จะเก็บหรือจะลบเพิ่มได้)
- ย้อนกลับ (Undo) และรีเซ็ตกลับเป็นรูปต้นฉบับ
- ซูมด้วย Ctrl + ล้อเมาส์ หรือแถบซูมมุมซ้ายล่าง
- บันทึกเป็น PNG, JPG หรือ WEBP

### Convert
- **PDF เป็น PNG** เลือกหน้าที่ต้องการและความละเอียด แล้วบันทึกแต่ละหน้าเป็นไฟล์ PNG ถ้าเลือกหน้าเดียว ส่งต่อไปแก้ใน Image Editor ได้ทันที
- **PDF เป็นข้อความ** ส่งไฟล์ไปยังเซิร์ฟเวอร์แปลงข้อความ (ตั้งค่าที่อยู่ผ่าน `VITE_PDF2TEXT_URL` ค่าเริ่มต้น `http://localhost:8000/pdf-to-text`)

## ติดตั้ง

ดาวน์โหลดไฟล์ติดตั้ง `CuthrusGlaucus_x.x.x_x64-setup.exe` แล้วเปิดเพื่อติดตั้ง

## พัฒนาต่อ

ต้องมี Node.js และ Rust

```bash
npm install
npm run tauri dev     # รันโหมดพัฒนา
npm run tauri build   # สร้างไฟล์ติดตั้ง (NSIS) ที่ src-tauri/target/release/bundle/nsis
```

สร้างด้วย Tauri, React, TypeScript และ Tailwind CSS
